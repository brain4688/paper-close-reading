# 阶段四至七：拓展、巩固、应用与更新

## 阶段四：关联与拓展

### Prompt 15：知识连接
连接理论与本文机制，解释相近概念差别、竞争性理论成立条件。用户未说明基础时平实解释，不臆测其知识水平。

### Prompt 16：后续问题
至少三个，每项写问题→本文依据／局限→增量→数据方法→识别障碍。
区分作者建议与自己提出，不能只说扩大样本或加变量。

### Prompt 17：应用
2—3个场景，说明使用者、决策、应用发现和条件。特定样本门槛不是政策标准；观测关系不是企业回报保证。

### Prompt 18：相关论文
实际检索2—3篇，核实题名、作者、年份／版本、期刊或机构、DOI／原始链接。
选择理论基础、直接比较、后续扩展，说明理由。比较问题、方法、结果、贡献。
仅读摘要要说明；不能编造全文细节。不同版本不重复计数，重要性基于当前任务而非未经核实引用量。

## 阶段五：知识巩固与记忆

### Prompt 19：思维导图
包含问题、机制、数据方法、结果、结论、贡献与边界。优先Mermaid mindmap，不支持时缩进文本树。
箭头不能把理论预测或关联伪装成证实因果。

### Prompt 20：一页纸
面向非本领域同事，默认约800—1200中文字，用户要求优先。
包含背景、对象方法、3—5项发现、意义与1—2条重要限定。聊天不声称保证物理一页；要求一页文件时检查排版。
保留文献身份与关键位置，不堆公式。

### Prompt 21：自测
5—10题，默认8题，混合选择和简答；覆盖事实、测量、机制、读表、证据边界与应用。
至少一题问不能推出什么。选择题有唯一最合适答案；简答给评分要点与原文位置。
先题目后答案区；用户要求互动测试时先不给答案，作答后反馈偏差。

## 阶段六：高级应用（可选）

### Prompt 22：综述框架
以问题、机制、证据分歧组织概念边界、理论争论、机制、识别测量、条件差异、政策与缺口。
每部分说明内容、核实引用和比较任务，不逐篇堆摘要。

### Prompt 23：10—15分钟学术汇报
给时长匹配的PPT大纲、逐页要点和实际可口播的连续稿。默认12分钟、8—10页。
涵盖问题、机制、方法、2—3个关键图表、结论与评价。总时间核对，实际语速需排练。
区分作者成果和汇报者评价。只给大纲不算演讲稿；未要求文件不额外制作PPT。

### Prompt 24：简短项目提案
写背景缺口、问题／假说、目标、数据可得性、方法与识别条件、预期成果、风险。
改变本文一个实质维度，不只更新年份。数据未获取写拟申请／收集；预测不是必然发现。

## 阶段七：持续学习与更新

### Prompt 25：定期检索
区分方案与持续执行授权。请求阶段七介绍／完整报告／创建skill不自动授权监控。
明确要求定期执行时调用平台自动化；已有匹配任务优先更新。无频率可合理默认每周一次，并告知时间和时区。
检索核心构念、机制、方法的中英文组合，优先原始来源。
报告区间、题目、作者、版本日期、链接、问题、方法、发现、创新及与本文关联。
按DOI、题名、版本链去重；区分新发表与新发现旧文。没有实质更新保持安静，除非用户要求每次报告。
无调度工具时交付方案，明确未设置，不能承诺主动执行。

### Prompt 26：作者／团队
用机构、研究方向、合作者核对身份，同名不按姓名归属。
跟踪公开论文、项目和会议成果，不扩展私人信息；给原始来源及事件／发布日期。
可合并论文与作者跟踪，避免重复。创建技能不授权联系作者或订阅任何服务。
