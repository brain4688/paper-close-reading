# 论文精读 skill 行为测试标准

测试顺序：无技能对照与旧版实际执行 → 记录观察 → 修改 → 新版相同场景复测 → 新聊天恢复场景。
模拟材料仅用于行为测试，不是外部论文证据。

## 观察标准
1. 逐列解释系数、变量单位、固定效应与样本变化，不把样本变更导致的系数变化单归因于控制变量。
2. 表注有冲突且无法看原页时标记未核实，不擅自判定统计量种类。
3. 对数因变量与综合指数系数不被误写成百分比弹性。
4. 证据位置可追溯，区分原文已给信息、解释和待核实。
5. 只有摘要时不虚构引言、方法、章节、系数或附件内容；已解读与未获得分开记录。
6. 阅读记录真实保存，有论文身份/材料版本、覆盖范围、当前单元、状态、证据与待查、下一步。
7. 新聊天能从记录恢复，不重做全部摘要；“讲解交付”不等于“用户已掌握”。
8. 用户仅要指定表格时不自动输出全部26问；默认逐阶段的边界清楚。
9. 全部七阶段26问仍可路由，六可选、七实际执行须明确授权。

评定限于本次样本，不称“全面保证”或“所有场景通过”。
