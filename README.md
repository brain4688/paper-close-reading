# 学术论文七阶段精读

可复用的 Codex skill：七阶段、26个问题，支持逐阶段教学精读、指定段落/公式/表格、完整报告，以及保存阅读进度。

## 安装

将 `skills/paper-close-reading` 文件夹复制到个人 Codex 技能目录 `~/.codex/skills/`（如已有同名技能，先保存自己的修改）。

## 使用

附上论文后调用：

```text
请使用 $paper-close-reading 带我逐阶段精读这篇论文。
```

同一工作区继续阅读：

```text
请使用 $paper-close-reading 继续上次的精读。
```

也可指定“完成阶段二和三”或“逐列解释表4”。默认教学模式，理解练习可选；要求报告模式时一次交付指定范围。

## 七阶段

| 阶段 | 问题 | 内容 |
|---|---|---|
| 一 | 1—4 | 概览、章节、贡献、关键词 |
| 二 | 5—9 | 引言、方法、结果、讨论、结论 |
| 三 | 10—14 | 方法与结果评价、创新性、逻辑和综合评价 |
| 四 | 15—18 | 知识连接、后续研究、应用与相关文献 |
| 五 | 19—21 | 思维导图、一页纸和自测 |
| 六（可选） | 22—24 | 综述、学术汇报与项目提案 |
| 七 | 25—26 | 新论文与作者动态跟踪方案 |

阶段七的实际定期跟踪需用户明确授权和可用的调度工具，安装技能不会自动创建监控。

## 阅读记录

默认在使用者工作区的 `paper-reading/` 下保存索引、笔记、证据表和进度。记录区分已扫描、已精读、材料缺失以及用户理解状态。不同论文与版本分别保存；原文不可用时不声称重新核验。

## 项目结构

- `skills/paper-close-reading/`：可安装技能及阶段指南。
- `tests/evaluation/`：修改前基线、无技能对照、新版复测和独立恢复测试的产物。全部测试论文为教学模拟。
- `scripts/validate.py`：结构、26问覆盖、引用与测试记录完整性检查。

## 验证

```sh
python -m pip install -r requirements-dev.txt
python scripts/validate.py
```

行为测试采用先测后改再复测：旧版默认不保存进度，新版验证了默认保存、摘要证据边界、按索引匹配论文以及从旧记录续读。参见 [验证报告](tests/evaluation/evaluation-report.md)。

这些测试未覆盖所有学科、真实PDF解析和全部七阶段行为，也不是论文实证复现。原始本机目录已替换为仓库相对标识；复跑行为场景时使用自己的工作区。仓库不包含毕业论文数据或原论文PDF。
