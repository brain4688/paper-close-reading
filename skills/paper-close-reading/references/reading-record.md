# 阅读记录、恢复与完成标准

这是默认带读的必读参考。保存是本skill的默认学习行为，用户明确不保存时仅聊天交付。

## 文件位置与身份

用户指定目录优先；否则在当前工作区创建：
```text
paper-reading/
  index.md
  <论文短题名-年份>/
    notes.md
    evidence.md
    progress.md
```
标题过滤文件名禁用字符；作者／年份未知写未知。同题名不同作者或版本增加简短身份后缀，不能覆盖旧记录。
index.md记录论文身份、相对目录、来源路径／DOI、版本、最近更新时间、下一单元。文件内链接可相对，聊天链接用绝对路径。

进度与证据可以基于用户转录、摘要或扫描材料建立，不必等待完整PDF。源文件来自临时目录时记录该事实，不默认复制或移动原文；源文件消失后保存笔记仍可读取，但不可宣称重新核验全文。

## 新聊天恢复顺序

1. 用户指定进度文件时先读该文件；否则检查工作区paper-reading/index.md。
2. 给了论文身份时匹配题名、作者、年份、DOI及版本；“继续上次”选择索引最近一次阅读，简短说明选择。
3. 只有“继续”且存在多个合理对象时提出一次必要澄清；在确认前不修改某篇进度。无记录但有聊天上下文时据上下文恢复并注明来源；新聊天无信息时不假装记得。
4. 读取所选progress.md、证据表和与下一单元相关笔记。核对源文件与版本；新版本保留旧记录，先确认哪些结论需要重核。
5. 只续读下一单元，不重复已交付全阶段。缺原文时可解释已保存材料并标明范围，不凭进度文件补造缺失证据。

## progress.md 必需字段

```markdown
# 阅读进度
- 论文身份：题名｜作者｜年份｜DOI或未知
- 原文来源：文件路径／网址／用户转录
- 版本与材料范围：全文／摘要／节选，附录是否获得，页码映射
- 模式：教学／报告
- 最近更新时间：含时区
- 当前阶段／问题编号：
- 当前原文位置／单元：
- 索引到笔记与证据表：

## 问题状态
| 编号 | 状态 | 已交付范围／位置 | 缺口或不适用理由 |
列出1—26；阶段六默认未开始且可选，七没有执行授权时记录方案与实际设置分别的状态。

## 阅读范围与理解
- 已扫描：
- 已精读／讲解：
- 用户理解：未知／用户自述／实际练习表现；写依据，不默认已掌握
- 关键概念与易错点：
- 待核实项及影响的主张ID：
- 下一步：具体位置、问题和所需材料
```

状态使用“未开始、部分交付、讲解已交付、材料受限、不适用”。部分讲解同时有材料缺口时用部分交付并列缺口。
“讲解已交付”只表示该问题所需内容已解释；不能据此宣称用户掌握。
“不适用”需具体理由，例如理论论文不适用实验分配检验；没有附件不是不适用。

## notes.md 与 evidence.md

notes.md按阶段、问题、原文单元组织，保存本轮具体讲解与已经得出的限定；继续读时更新同一文件，不反复附加重复全文。
evidence.md：
| 主张ID | 作者命题 | 位置 | 核验范围 | 证据／关键值 | 解释与支持边界 | 待查 |
核验范围写原页／提取文本／用户转录／摘要，不混淆。自提出研究建议标“读者延伸”，不假装原文命题。
缺失证据保留待查行，找到材料后更新并注明更正；不要同时保留两个不加说明的矛盾结论。
每轮先保存笔记与证据，再更新进度和索引。使用可用文件工具；写入失败就明确尚未保存，不能凭生成的文本声称落盘。更改已有文件保留用户批注与手工修改。
用户不想管理文件时告知保存路径即可，不把维护记录变成用户额外任务。

## 阶段完成标准

| 阶段 | 可称完成的条件 |
|---|---|
| 一1—4 | 三句话、原文章节地图、初步贡献、5—10关键词都有依据；只见摘要则章节地图材料受限 |
| 二5—9 | 主要论证、关键概念与适用公式／图表已解释，问题—证据—结论对应；仅概括或列方法名不足 |
| 三10—14 | 方法、结果、创新、逻辑和综合评价具体有据；说明替代解释与作者补救，未核验的比较保留限定 |
| 四15—18 | 知识连接、至少三个后续问题、2—3场景与2—3篇实际核实研究齐备；检索未完成不能假装已比较 |
| 五19—21 | 导图、一页纸、自测题与独立答案已交付；用户掌握程度仍单独记录 |
| 六22—24 | 按所选任务完成框架、真实口播稿／大纲或提案；未选任务为未开始，可选 |
| 七25—26 | 区分方案交付、自动化已设置和未来运行结果；一次安排不能称持续跟踪已完成 |

仅指定局部任务时按局部验收，不要求为完成表格解释而输出全阶段。
结尾写“本次完成……；下一单元……；进度保存在……”。每阶段状态基于覆盖范围，不基于输出字数。
