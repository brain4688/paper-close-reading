# 阶段一至三：理解与评价

## 阶段一：快速概览与初步印象

### Prompt 1：三句话
严格三句话：核心主题与矛盾；目的及主要方法／对象；主要发现及范围。未读内容不加入。

### Prompt 2：结构
列真实章节与主要小节标题、位置、大致内容；说明各部分在论证中的任务。不用通用结构替代原文章节。

### Prompt 3：初步贡献
提取作者自述，再给初步判断，区分理论、机制、数据、识别、方法和应用增量。终评留到12。

### Prompt 4：关键词
5—10个，解释本文语境中的含义及重要性，覆盖解释变量、结果、机制与方法。

## 阶段二：深入细节与理解内容

### Prompt 5：引言
逐一回答：试图解决的问题；背景和铺垫；明确研究问题；自述贡献。
梳理现实事实→理论争论→经验缺口→研究任务。检查跨页贡献续项。区分原文明示与读者归纳，不能把作者声称的缺口当成已核实事实。

### Prompt 6：方法
逐一回答方法类型、具体实施、关键变量／指标、作者提到的局限／偏差、选择理由。
- 理论：主体、行为、目标、约束、假设、均衡与推导。哪些机制形式化，哪些仅文字解释。
- 实证：数据来源、时间、样本筛选、观测单位、缺失处理、测量层级、单位、权重、估计式、识别假设、标准误。
- 实验：处理分配、对照、测量、依从性和流失。
- 定性：案例选择、材料、编码、验证与研究者影响。
解释每种方法对应哪个问题。说明理论构念与代理指标差距。附录未获得时不猜测实施细节，不假装复现。
区分作者承认的局限与本次识别的潜在偏差。

### Prompt 7：结果
回答主要发现、2—3个关键图表、与引言问题的对应、异常发现、统计显著性。
建立问题／假说→模型／表格→结果映射。解释表格每列的变量、系数、单位、样本与设定变化。
报告效应大小与不确定性，不只星号。分组／门槛结果核查区间样本与差异检验；机制回归解释额外识别条件。
对数、标准化、复合指标不能随意换算百分比；换算时写假设。
表注冲突核对原页和附件，未解决标记。子结果与总结果不同要保留，不强行说所有假说均支持。

### Prompt 8：讨论
没有独立章节时定位分散讨论。回答结果解释、既有研究比较、意义、局限、未来方向。
区分直接检验机制与相容解释。比较时检查指标、样本、识别是否可比。
没有系统讨论局限或未来计划时明确说明；自己的延伸单列。

### Prompt 9：结论
提取核心论点，检查贡献与意义、引言呼应、未来或应用。
结论强度不能超过证据。政策建议不等于已估计政策效果，说明适用范围与常见误读。

## 阶段三：批判性思考与深入理解

### Prompt 10：方法评价
给具体优点、不足及替代方法。每项不足包含原文依据→受影响结论→作者补救→剩余问题→可行改进。
实证评估构念、内生性、样本、模型、推断和复现；理论评估假设、推导、敏感性及经验对应。
替代方法说明所需数据、识别条件和代价，DID、RDD、IV与结构估计并非自动更优。

### Prompt 11：结果评价
分别判断描述关系、条件相关、因果效应、机制、动态过程、政策外推可信度。
用结论→证据→支持程度→替代解释表。可以定性分级，不能虚构量化评分。
考虑反向因果、趋势、测量、选择与共同因素，并给区分解释的检验。未排除不等于已证明存在。
附录未核验不指控作者没有检验，应标记材料边界。

### Prompt 12：创新性
以核实文献比较理论、机制、数据、识别、应用增量；区分新情境验证、新指标、新识别、新理论。
说明学术与实践价值，模型扩展也可能有价值。没有系统检索只作局部比较，不宣称首次或排名。注意工作论文和正式版本的时间关系。

### Prompt 13：逻辑
追踪问题→假说→模型→测量→结果→解释→结论。
检查概念偷换、层级错配与跳跃：理论创新率／专利量、市场势力／集中度、区间／时间阶段、中介关联／因果机制、显著性／经济意义、企业证据／平台政策。
指出衔接顺畅之处和具体薄弱环节，不用篇幅代替逻辑评价。

### Prompt 14：综合评价
按问题、方法、结果、讨论、结论给主要优缺点及影响。优先决定性问题，避免重复10—13全部内容。
给出适合引用来支持什么、必须加哪些限定。
